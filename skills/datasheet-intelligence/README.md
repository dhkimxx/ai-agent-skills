# datasheet-intelligence

> 데이터시트(PDF/DOCX/XLSX)에서 **근거 있는 하드웨어 사실**과 초기화 코드를 뽑는 스킬.
> 문서 전체를 읽지 않고 "찾고 → 읽고 → 다시 찾는" 루프를 따릅니다.

- **설치**: `npx skills add dhkimxx/ai-agent-skills --skill datasheet-intelligence`
- **요구 사항**: Node.js(npx), `uv`(Python 스크립트 실행)
- 최초 작성 2026-02-19 · 갱신 2026-03-12

## 왜 만들었나

642쪽 데이터시트로 실험한 기존 방식의 한계:

| 방식 | 문제 |
|---|---|
| 전문 텍스트 추출 | 목차·헤더·테이블 레이아웃이 깨짐 |
| `grep` 키워드 검색 | 해당 내용이 많아 컨텍스트에 담기지 않음 |
| 멀티모달 렌더링 | 시간·토큰 소모가 큼 |
| **키워드 탐색 루프(채택)** | 필요한 페이지만 읽어 문서 참조율이 가장 높음 |

## 동작 흐름

```
1. toc.py     — 문서 구조(목차) 파악
2. search.py  — 키워드가 있는 페이지 번호 탐색
3. read.py    — 해당 페이지만 선택적으로 읽기
4. 부족하면 새 키워드로 2–3 반복
```

테이블·헤더 보존이 중요하면 `--structured`(docling 기반)로 마크다운 형태 파싱을 씁니다.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `SKILL.md` | 에이전트 지침(워크플로우, 제약) |
| `scripts/toc.py` | 목차 추출 |
| `scripts/search.py` | 키워드 검색 |
| `scripts/read.py` | 페이지 단위 읽기 |
| `references/usage.md` | 사용법 상세 |
| `pyproject.toml` · `uv.lock` | 의존성(uv) |

## 사용 예

```
워크스페이스의 docs/rp2040.pdf를 참고해 I2C0 컨트롤러를
100kHz 마스터 모드로 초기화하는 C 코드를 작성해.
레지스터 주소와 비트 설정은 데이터시트 근거여야 해.
```

에이전트는 목차 확인 → 키워드 검색 → 페이지만 읽기 순으로 동작하고,
결과에 **파일명 + 페이지 번호** 근거를 붙입니다.
