# 발행 전 체크리스트

## 공통 (13항)

1. **독자 정의** — 첫머리에 독자 수준·선행 지식·읽는 시간이 있는가?
2. **유형 일치** — 문서 유형(튜토리얼/하우투/레퍼런스/설명/교재/브리프)이 하나로 정해졌고 그 골격을 따르는가?
3. **용어 첫 등장 풀이** — 낯선 용어를 처음 나올 때 정의했는가? (필요하면 비유까지)
4. **용어 일관성** — 같은 개념에 같은 단어를 썼는가? (응답/리턴/결과 혼용 금지)
5. **문장 길이** — 60자를 넘는 문장이 없는가?
6. **문체** — 능동태인가? 번역투("~에 의해", "~되어진다")가 없는가?
7. **수치 근거** — 수치마다 단위와 근거 태그가 있는가? (태그: `[검증]`/`[측정]`/`[추정]`/`[인용]`)
8. **그림·표** — 번호·제목이 있고 본문에서 참조했는가? (그림 N — 제목)
9. **코드** — 복사해 바로 실행 가능한가? 실행 결과·예상 출력이 함께 있는가?
10. **요약** — 요약/결론만 읽어도 전체 흐름이 잡히는가?
11. **범위** — "다루지 않는 것"을 밝혔는가?
12. **소리 내어 읽기** — 어색하게 걸리는 문장이 없는가?
13. **리뷰** — 동료 1인에게 보여줬는가? (초보자 대상이면 **초보자 리뷰어**)

## 유형별 추가 점검

### 튜토리얼
- 각 단계에 **예상 결과**가 있는가?
- 중간에 이론 강의가 끼어들지 않았는가? (설명 문서로 분리)
- 준비물의 **버전**을 밝혔는가?

### 하우투
- 에러 메시지 **원문**을 넣었는가?
- 원인 후보별 **확인 방법**이 있는가?
- 되돌리는 방법(롤백)을 적었는가?

### 레퍼런스
- 기본값·타입·제약이 빠짐없이 있는가?
- 항목마다 예제가 최소 1개인가?
- 문서가 코드에서 자동 생성되는가? (가능하면 자동 생성)

### 설명
- 문제 → 해결 순서로 서술했는가? (패턴 H)
- **반례**(안 되는 경우)가 있는가?
- 비유 뒤에 실제 정의가 따르는가?

### 교재
- 학습 목표(3~5)와 확인 문제(답 포함)가 있는가?
- 새 용어가 절당 3개 이하인가?
- 용어 카드(등장 순서)가 부록에 있는가?

### 브리프
- 요약문에 **결론**이 들어 있는가?
- 핵심 숫자 1~3개로 압축했는가?
- "더 볼 것" 링크가 살아 있는가?
